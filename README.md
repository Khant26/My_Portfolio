# Khant Maung - Developer Portfolio

Personal portfolio for Khant Maung, a full-stack developer based in Pathum Thani, Thailand.

## Live site

https://khantmaung.com/

## What it includes

- Work experience and technical skills
- Four focused project case studies
- Live GitHub profile, repository, avatar, and public activity data
- Dark and light themes
- Responsive layout
- Downloadable CV

## Built with

This is a dependency-free static site built with semantic HTML, CSS, and JavaScript. It is deployed on Vercel.

## Run locally

Open index.html directly or serve the directory with any static file server.

## Deployment

Vercel serves index.html from the repository root at https://khantmaung.com/.
